# Multiplayer acceptance checklist

- [ ] Host and at least one Client can join the same lobby/room.
- [ ] Two to four vehicles spawn with correct ownership.
- [ ] Countdown is identical on all clients.
- [ ] Vehicles remain smooth at 50-100 ms simulated latency.
- [ ] Checkpoints must be passed in order; three laps finish consistently.
- [ ] Pickup and item effects are server-validated and replicated.
- [ ] All clients show the same finish order and result screen.
- [ ] Disconnect returns remaining players safely to the lobby.
- [ ] Console has no important errors or warnings.
