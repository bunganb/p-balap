# Documentation

Panduan utama networking untuk seluruh tim berada di [`Docs/NETWORKING.md`](../../../Docs/NETWORKING.md).

Keep short, actionable notes here:

- `architecture.md` - Netcode ownership and vehicle data flow.
- `test-checklist.md` - Host + 1-4 clients, 50-100 ms latency, packet loss, disconnect, finish consistency.
- `weekly-status.md` - six-week milestone status and merge notes.

Every feature should document how to run it and how it was tested in a build or two editor instances.
