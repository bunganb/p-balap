# Scenes

Planned scenes:

- `Bootstrap` - service initialization and network entry point.
- `Lobby` - Host/Join, player list, Ready, Start Race.
- `Race` - one track, start grid, checkpoint sequence, race HUD, debug overlay.
- `Results` - server-sourced finish order, Rematch, Back to Lobby.

Keep scenes small and additive-friendly. Do not store generated Library data in Git.
